# 开发验收记录

已将用户确认的 V3 设计接入独立静态站源代码，而不是继续修改设计稿。

## 交付

- 4 个工具页面：Rift 首页、Europe、Asia、Reset。
- 3 个说明页面：来源、版权与原项目署名、隐私。
- 共享 JSON 数据、纯时间计算模块、配置校验、提醒、日历、偏好与个人清单。
- 无数据/过期数据禁止推测倒计时；加载失败提供明确消息与 Retry。
- 删除用户侧图片编辑和设计控制；保留已确认视觉及三场景切换。
- Node 内置构建/服务、Cloudflare Pages 输出、GitHub/GitLab 检查配置。
- 原版文件保存在 docs/legacy/，原 README 保留在 docs/UPSTREAM-README.md。

## 验证

`npm run check`：6 组测试，覆盖字段缺失、非法时区、错误来源引用、发布状态、午夜边界、日/周重置、KR 日期转换、美国 DST、过期数据、空数据与非法时间参数；构建成功。

`tests/browser.cjs`：使用 Edge / Playwright 对实际 dist 输出验收：

- 7 页正常加载，320 / 390 / 768 / 1440 宽度无横向溢出。
- 场景切换、本地/UTC、区服与 4/8 场列表。
- Asia 待核实：计时、提醒、日历、Reset 清单不会采用其他区域的时间。
- 通知拒绝后页内提示及停止提醒。
- ICS 56 场且带选择的提前量。
- Reset 清单刷新后保存，清空可用。
- 数据 HTTP 失败后重试恢复；非法时区配置给出错误码；过期配置停止倒计时。
- /rift-timer/eu/ 返回 301，未知页面返回 404。
- 无非预期浏览器控制台或运行错误。

已查看正式构建的电脑与手机整页截图，布局保持 V3。
