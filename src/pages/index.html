06 / BEFORE YOU GO

A few things
worth knowing.

Short answers.
More time in Atreia.

Does zero mean the portal is open?＋

No. This is a schedule-based estimate, not a live server feed. Confirm the portal on your in-game map.

Are these confirmed game schedules?＋

Current data is provisional and uses example times. Current official notices and dated observations are needed before launch. No “tested in game” claim is made.

Can I get a reminder before an opening?＋

Use Set a demo reminder. Browser alerts need this tab open and can be delayed. Calendar downloads are a one-time import of marked DEMO events.

Will my local time handle daylight saving?＋

Yes. Each date is converted with your browser’s IANA time zone. The correct game-service schedule still needs independent verification.

Where are the actual portal locations?＋

Use the in-game map during an opening. The promotional art on this page is atmosphere, not a location map or evidence of a tested portal.
