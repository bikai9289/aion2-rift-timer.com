THE SHORT ANSWERS

Good to know.

Are these verified times?＋

Not yet. This is a pre-release tool using example schedules. Official, service-specific data and in-game observations are needed before launch.

Will reminders work with this tab closed?＋

No. Browser alerts need this tab open and can be delayed. Calendar downloads are a one-time import of clearly marked demo events.

Does daylight saving change the countdown?＋

Local conversion accounts for daylight saving at each date. It does not prove which event anchor a game service follows.
